# Orçun Aytekin Projects

Adana merkezli lüks konut projelerinin tanıtım web sitesi.

Tek dosyadan oluşan statik bir sitedir (`index.html`) ve GitHub Pages ile yayınlanır.

## Düzenleme

`index.html` içindeki `SITE` ve `PROPS` bölümleri:

- `SITE.owner`: ad, telefon, WhatsApp, Instagram, fotoğraf
- `SITE.office`: ofis adı ve Google Haritalar bağlantısı
- `PROPS`: konut projeleri (başlık, konum, oda/banyo/otopark, açıklama, ilan linki)
- `ORDER`: koleksiyondaki kartların sırası
